# Использование ИИ — B

Запрос человека: выполнить роль B по AGENTS.md — профиль восьми raw-таблиц,
передача фактов A и ETL по контракту. Человек сообщил, что Docker запущен,
а контракта пока нет. Других согласований модели от человека не получено.

ИИ подготовил SQL-профиль, отдельную среду PostgreSQL и загрузку из источника
раздатки, проверил их на 550 759 строках. Сохранены SQL, JSONL и SHA-256 файлов.
Первый запуск остановился на запрете CREATE TEMP TABLE в READ ONLY; режим исправлен.
Затем медленная проверка FK отменена и заменена соединением с уникальными ключами
родителя. Итоговый полный профиль завершился успешно (138 агрегатных записей),
точечные проверки категорий/типизированных ключей/ZIP тоже успешно выполнены.

Предложение ИИ для A: составной ключ отзыва, сохранение исходных дат/NULL/текстов,
раздельная обработка отсутствующей категории и отсутствия перевода. Решение A
пока отсутствует; предложение не выдаётся за согласованный контракт.
ETL не реализован и не запускался: нет core DDL и контракта.
Проверка после появления контракта: команды сборки A с `psql -X -v ON_ERROR_STOP=1`,
сверка 8 источников, количества и денежных сумм, затем проверки D.
