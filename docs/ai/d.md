# Использование ИИ — D

Пользователь поручил независимые проверки, документы защиты и PR. Последнее
ограничение: файлы A не менять; использовать четыре файла B. Затем пользователь
попросил остановить проверки и завершить письменные материалы. Это выполнено.

ИИ подготовил SQL, синтетическую фикстуру, runner и актуализировал документы D.
Решения человека: полный payload с метаданными; календарь по всем датам; тексты
отзывов как в raw; PR в main. Согласование итоговой модели человеком не выдумывается.

Подтверждено D на PostgreSQL 16.14: синтетика 11/11, проба четырёх файлов B PASS;
8 SHA-256/размеров совпали, полный raw 550 759 строк. Первый сохранённый core
прошёл 6 обязательных SQL, 3 отчёта и 2 baseline; пять таблиц результатов совпали
с CSV C. Первый клиент ранее достиг 300s; это не успешный exit code сборки.
Повторный прогон остановлен по просьбе пользователя; два совпавших fingerprints
не заявляются. Временный контейнер D остановлен, БД команды не менялась.

Старый блокер trim B устранён. Штатный build A всё ещё вызывает удалённый
20_load_core.sql; контракт A описывает прежний интерфейс. Они не изменялись.
Полный тестовый драйвер и входы оставлены локально в игнорируемом checks/local;
в PR входят только актуальные материалы/интерфейс D. Протокол — docs/defense.md.
