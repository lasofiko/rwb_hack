# Использование ИИ — D

2026-10-28. Пользователь назначил роль D и разрешил сделать максимум до готовности A;
вопросы необходимо сначала обсуждать с пользователем. Другие роли не запускались.

Предложение ИИ: отдельные синтетические проверки на fanout, unknown, календарь,
повторные покупки, NULL и кратность платежей/отзывов; каталог и fingerprints для
пересборки; проект документов сдачи. ИИ подготовил файлы только в зоне D.

Реальное решение человека: выполнить независимую подготовку без готовой ветки A.
Утверждения человеком формул, контракта, SLA и финальной приёмки пока нет.

Проверка: среда осмотрена; psql не найден, Docker Engine недоступен.
SQL и модель **не запускались**. Будущие команды и зависимости — в checks/README.md.
Статически проверены 11 файлов: пути SQL include, отсутствие хвостовых пробелов,
парность разделителей $$ и лимит статуса D. Python Decimal независимо подтвердил
контрольные суммы синтетики 126.25 и 35.35. Это не проверка синтаксиса PostgreSQL
и не замена выполнения SQL и независимой сверки данных.
